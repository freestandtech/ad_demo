# ChatGPT Ads demos

Interactive, step-by-step walkthroughs of running ads on ChatGPT through OpenAI Ads Manager (beta). Open either file in a browser and use Back / Next, the arrow keys, or Autoplay.

| File | Demo | Steps |
| --- | --- | --- |
| `index.html` | Publishing a first ChatGPT ad, using the Future Officers Academy campaign as the example | 17 |
| `kerastase-sampling.html` | Running a Kérastase Genesis serum free-sample campaign, ending with a preview of the ad inside a ChatGPT answer and the claim flow | 20 |

Link to a specific step by adding `#s1`, `#s2` and so on to the file's URL.

Ads Manager screens are recreations from a screen recording made on 28 Oct 2026. Tax IDs, emails, URLs, claim pages and performance figures are placeholders. The ChatGPT preview and product bottle are illustrations, not real placements or brand assets.
