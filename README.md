# ChatGPT Ads Walkthrough

An interactive, 17-step demo of publishing an ad on ChatGPT through OpenAI Ads Manager, from sign-up and business verification to a published campaign.

Open `index.html` in a browser. Use Back / Next, the arrow keys, or Autoplay. Link to a specific step with `#s1` to `#s17`.

Screens are recreations of Ads Manager (beta) as of October 2026. Tax IDs, addresses, pixel IDs and emails are placeholders.
